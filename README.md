# Riddam Goswami — Portfolio

A modern, responsive developer portfolio built with React and Vite to showcase my professional experience, technical skills, projects, education, and certifications.

## ✨ Features

- Responsive portfolio design
- Animated hero section
- Interactive custom cursor
- Scroll-based animations
- About Me section
- Skills and technologies showcase
- Professional experience timeline
- Project showcase
- Education and certifications
- Downloadable resume
- Contact and social links
- Mobile responsive design
- Accessibility-friendly reduced-motion support

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Git & GitHub
